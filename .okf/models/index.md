# Models

* [QuickAdd](quick-add.md) - free-text task title parser (priority, date/time, project, recurrence).
* [Recurrence](recurrence.md) - the "every(!)? (count)? unit" grammar and next-due-date computation.
* [Task](task.md) - the core domain object; due-date composition, completion, list scopes.
* [OsNotifier](os-notifier.md) - native OS notification shell-out (macOS / WSL2).
* [Project and Label](project-and-label.md) - lightweight organizing tags.
* [CompletedOccurrence](completed-occurrence.md) - immutable snapshot of a completed task.
